# Test Document

Kế hoạch và kết quả kiểm thử FoodMap. Mọi test case phải truy ngược được về một mã
yêu cầu trong `../SRS/srs.md`.

## Nội dung thuộc thư mục này

| Tài liệu | Mô tả |
|---|---|
| `test-plan.md` | Phạm vi kiểm thử, phương pháp, môi trường, nguồn lực |
| `test-cases.md` | Test case chi tiết, mỗi case trỏ về mã `FR-` hoặc `UC-` |
| `test-matrix.md` | Ma trận phủ theo vai trò × tính năng |
| `regression-checklist.md` | Danh mục kiểm thử hồi quy trước mỗi lần phát hành |
| `test-summary.md` | Báo cáo tổng hợp kết quả sau mỗi đợt kiểm thử |

## Lưu ý

Test case viết từ tiêu chí nghiệm thu trong `../SRS/acceptance-criteria.md`.
Tiêu chí không đo được thì không viết được test case — trả ngược lại cho SRS sửa,
đừng tự suy diễn.
